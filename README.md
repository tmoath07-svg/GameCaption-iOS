# GameCaption iOS 0.2.0

تطبيق iPhone مستقل لترجمة نصوص الألعاب. مشروع SwiftUI مفتوح المصدر **ليس نسخة من كود أو موارد** تطبيق Side Screen.

## الميزات المنفذة في الكود

- استيراد لقطة شاشة من الصور أو تطبيق «الملفات»؛ Vision OCR يتعرّف على النص.
- فحص كاميرا الآيفون بشكل متكرر (نحو مرة في الثانية) لقراءة نصوص الشاشة الخارجية.
- ميكروفون الآيفون مع Speech framework للتعرف على الكلام المسموع (يدعم التفريغ على الجهاز فقط عندما يتيحه النظام للغة المختارة).
- ترجمة النص باستخدام Apple Translation framework (iOS 18+؛ قد تحتاج لغات يتم تنزيلها من نظام iOS).
- دعم لغات متعددة (حسب دعم النظام للجهاز واللغة)، وعرض ترجمة، نطقها، نسخها ومشاركتها.
- سجل محلي لأحدث 100 ترجمة؛ يمكن الحذف من السجل.
- خادم HTTP محلي على منفذ 8877 لعرض الترجمة داخل متصفح جهاز آخر على نفس شبكة Wi-Fi، مع مفتاح دخول متغير بالرابط.
- واجهة عربية بتصميم iPhone فقط، بدون اشتراكات أو حسابات.

## المهم: الحدود المعروفة

- **لا يتصل ببث Xbox أو PlayStation Remote Play مباشرة**، ولا يحلل بث شاشة تطبيق آخر من الخلفية.
- عرض الترجمة في متصفح التلفزيون **لا يضعها تلقائيًا فوق HDMI أو فوق اللعبة**. يتطلب عرض المتصفح/صورة داخل صورة يدعمها التلفزيون.
- خدمة التلفزيون تعمل في مقدمة التطبيق فقط، وليس في الخلفية أو الشاشة المقفلة. أي شخص يعرف رابط المتصفح على نفس الشبكة يستطيع قراءة النص حتى تتوقف المشاركة.
- قد لا تدعم Apple Translation أو Apple Speech جميع أزواج اللغات، وبعض الوظائف تتطلب تنزيل نماذج لغة أو اتصالًا بالشبكة حسب إعدادات iOS.
- لا يشمل المشروع النماذج أو المكتبات أو الملفات الخاصة بتطبيق مرجعي آخر.
- لا توجد اختبارات فعلية لعتاد Xbox/PS أو تلفزيون أو تثبيت ESign حتى يجرّب ذلك على الأجهزة الحقيقية.

## بناء IPA عبر GitHub Actions

ادخل [Actions](https://github.com/tmoath07-svg/GameCaption-iOS/actions) → **Build and verify GameCaption IPA**.
المسار يعمل تلقائيًا عند الدفع إلى `main`، وينتج `GameCaption-iPhone-unsigned-IPA` بعد نجاح بناء المحاكي، الاختبارات عند توفر محاكي، بناء الجهاز والتحقق من الأرشيف.
الـIPA **غير موقّع** ويحتاج شهادة توقيع مناسبة (مثل ESign). لا يثبت مباشرة من GitHub.

## بنية المشروع

- `GameCaption/`: تطبيق SwiftUI + Vision + Speech + Apple Translation + Network.
- `GameCaptionTests/`: اختبارات حفظ الترجمات والتسلسل.
- `scripts/validate_source.py`: تحقق من استقلال المصدر ومحتويات IPA.
- `project.yml`: تكوين XcodeGen لهواتف iPhone فقط.

## الخصوصية والحقوق

لا يُرفع محتوى الصور إلى خوادمنا ولا يوجد حساب أو اشتراك. مزايا التعرف أو الترجمة التي يقدّمها النظام تخضع لسلوك واجهات Apple وإعدادات الخصوصية. الاستماع يتطلب موافقة صريحة ويُوقف من داخل التطبيق. رابط LAN مؤقت ولا يجب مشاركته خارج الشبكة.

هذا إصدار تطويري. نجاح GitHub Actions يثبت نجاح البناء والاختبارات المفعّلة، لكنه ليس إثباتًا لوظائف غير متاحة تقنيًا أو لم تُختبر على الأجهزة.
